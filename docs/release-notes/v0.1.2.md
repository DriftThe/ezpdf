# 中文

## 亮点

**翻译模型现在支持三种接口协议**：除了原有的 OpenAI 兼容 **Chat Completions**，新增 Anthropic **Messages** 与 OpenAI **Responses**。此前这两类协议只能识别、不能调用（263 + 86 个模型被挡在下拉框外），现在直接可用——Claude、GPT-5 系列等模型选好供应商就能翻。选「自定义」端点时还可以自己指定协议。

**设置改动自动保存**：任何设置改动在 2 秒后自动写入 `config.json`，不必先退出设置页；左上角返回键仍然是立即写一次。写入仍受「成功读取过配置」这道闸保护，不会用默认值覆盖你的配置。

**新的应用图标。**

**修复：安装版找不到翻译提示词**。此前提示词目录只在开发环境（源码目录）下能解析出来，用安装包安装后翻译会因为缺少系统提示词而失败；现在按「环境变量 → 安装目录资源 → 源码目录」的顺序解析，安装版正常可用。

## 新增

协议选择行（位于「供应商」下方）：预设模型的协议由内置模型目录决定、只读展示；「自定义」端点可手选 Chat Completions / Messages / Responses，Base URL 的示例与自动补的请求路径都跟着协议走。

「验证」按钮按协议探测关闭思考模式的策略：Chat Completions 保持原来的四种候选并发探测，Messages / Responses 依次尝试并在第一个「不再思考」的响应处停下。Anthropic 走 `x-api-key` + `anthropic-version`，Responses 走 `reasoning.effort`；这两种协议下若模型可能仍在思考则不再发送 `temperature`（两个 API 都会拒绝「温度 + 思考」并存）。

「获取在线列表」同样按协议请求（Anthropic 是 `/v1/models`）。

设置页去掉了若干重复的说明文字（默认行为写在文档里）。

## 修复

- 安装版找不到翻译提示词（见「亮点」）。
- 「验证」不再误报「无法关闭思考模式」：只有当探测到的响应里真的还带思考内容时才告警；端点本就不需要该参数的协议（如 Anthropic 关思考需显式字段、或目录未给出 off 值的推理模型）不再弹警告。
- 表格补翻、已翻译页面不再回翻等既有行为保持不变。

## 内部

- 模型目录精简：只保留界面与请求真正读取的字段，设置页懒加载的这块数据从 394KB 降到 228KB；可用模型数从 405 升到 754（因为多了两种协议）。
- 去掉了为已删除界面元素服务的代码与文案，合并了若干重复实现（无行为变化）。
- 解析服务的镜像快照改为**独立 Release** 发布，不再附在应用 Release 下：见 `pyserver-v<版本>` Release（由 Pyserver images workflow 手动构建，首次为 draft，需手动转正）。

## 安装与升级

- **Windows**：下载 `ezpdf_0.1.2_x64-setup.exe` 安装。安装包未签名，首次运行会有 SmartScreen 提示，选择「仍要运行」即可。
- **Linux**：Debian/Ubuntu 用 `.deb`，Fedora/RHEL 用 `.rpm`。
- 直接覆盖安装即可；仓库目录里的 PDF 与解析 JSON、以及你的设置都不会被安装包动到。
- **首次使用**：在 设置 → OCR 选择「本地托管」并点击「一键安装服务」（约 1.9GB 模型，可切换国内镜像源），再到 设置 → LLM 填好 API Key，即可开始翻译。

# English

## Highlights

**Three wire protocols for translation models**: alongside OpenAI-compatible **Chat Completions**, the client now speaks Anthropic **Messages** and OpenAI **Responses**. Those two were previously identifiable but uncallable (263 + 86 models were hidden from the dropdown); now they just work — pick a provider and Claude or the GPT-5 family is ready to translate. Custom endpoints let you pick the protocol yourself.

**Settings save themselves**: any change is written to `config.json` two seconds later, so you no longer have to leave the settings page first; the back button still writes immediately. Writes stay gated on a successful load, so your config is never replaced by defaults.

**A new application icon.**

**Fix: installed builds could not find the translation prompts.** The prompt directory was only resolvable in a source checkout, so a packaged install failed to translate for lack of the system prompt. It is now resolved as environment variable → bundled resources → source directory, which makes installed builds work.

## New

A protocol row under the provider field: for preset models the protocol comes from the bundled model catalog and is shown read-only; custom endpoints can pick Chat Completions / Messages / Responses, and both the Base URL example and the appended request path follow that choice.

The verify button probes thinking-off strategies per protocol: Chat Completions keeps its four concurrent candidates, while Messages / Responses try them in order and stop at the first reply that is not thinking. Anthropic uses `x-api-key` plus `anthropic-version`, Responses uses `reasoning.effort`; under those two protocols `temperature` is omitted while the model may still be thinking, since both APIs reject a temperature combined with an active reasoning mode.

Fetching the online model list follows the protocol as well (Anthropic lists `/v1/models`).

Several redundant explanatory lines were removed from the settings panes (the defaults are documented instead).

## Fixes

- Installed builds could not find the translation prompts (see Highlights).
- Verify no longer reports "thinking mode could not be disabled" spuriously: it warns only when a probe response actually still contains reasoning, so protocols that simply need no parameter stop showing the warning.
- Existing behaviour (table backfill, no re-translation of finished pages) is unchanged.

## Internal

- The vendored model catalog only keeps the fields the UI and the requests actually read — the lazily loaded chunk shrank from 394KB to 228KB. Usable models went from 405 to 754 thanks to the two new protocols.
- Code and copy that served removed UI elements were dropped, and a few duplicated implementations were merged (no behaviour change).
- Parse-service image snapshots now live in their **own Release** instead of being attached to the app Release: see the `pyserver-v<version>` release (built on demand by the "Pyserver images" workflow; the first one is a draft that has to be published).

## Install / upgrade

- **Windows**: run `ezpdf_0.1.2_x64-setup.exe`. It is unsigned, so SmartScreen will warn — choose "Run anyway".
- **Linux**: `.deb` for Debian/Ubuntu, `.rpm` for Fedora/RHEL.
- Just install over the previous version; your repo (PDFs and parse JSON) and your settings are untouched.
- **First run**: open Settings → OCR, keep "local" and click "one-click install service" (~1.9GB of models, a China mirror is available), then fill in your API key under Settings → LLM.
